VST3 в FL Studio

FL Studio читает VST3 только из системной папки, не из произвольного каталога сборки.

  1. Распакуйте zip.
  2. Скопируйте spectralizer-vst.vst3 в C:\Program Files\Common Files\VST3\.
  3. F10 → Manage plugins → Verify + rescan.
  4. Browser → Plugin database → Effects → VST3 → Spectralizer.

Сборка из исходников

Нужны Node.js 20+ и, для плагина, Rust stable. Проект лучше держать вне OneDrive.

git clone https://github.com/grishinskeo-ship-it/Spectralizer.git
cd Spectralizer
npm install
npm run pack:portable   # Windows .exe
npm run build:web       # copy the web app into docs/app
cd vst
cargo xtask bundle spectralizer-vst --release
