# 🖥️ Desktop-приложение

## 🎯 Назначение

Анализ **загруженного аудиофайла** в выбранный момент времени (и при воспроизведении — live-обновление спектра).

## 📑 Вкладки

| Вкладка | Функция |
|---------|---------|
| 📊 **Анализ** | Magnitude spectrum, zoom по частоте, сетка, пик |
| 🌀 **Фаза** | Фазовый спектр |
| 🔁 **Resynth** | Просмотр и прослушивание resynth по FFT-кадрам |
| 🎹 **VCV VCO** | Модель partials для VCV Rack, экспорт CSV |

## 🎚️ Настройки анализа

- **FFT:** 256 … 8192  
- **Окно:** Rectangular, Hanning, Hamming, Blackman  
- **Канал:** mono / left / right  
- **Частота:** linear / **log**  
- **Амплитуда:** linear / **dB** (мин/макс dB)  
- **Сглаживание**, сетка, маркер пика, гармоники  

> 💡 Для чистого спектра предпочитайте **Hanning** вместо Rectangular.

## 🎬 Workflow

1. 📂 Перетащите файл или выберите через диалог  
2. ▶️ Воспроизведение или клик по waveform  
3. 🔍 При необходимости — zoom на спектре (выделение мышью)  
4. 🎹 На вкладке VCO — скопируйте CSV для Rack
