# ⚙️ Установка и сборка

## 📥 Готовые сборки (Releases)

Скачайте с [GitHub Releases](https://github.com/grishinskeo-ship-it/Spectralizer/releases):

| Файл | Описание |
|------|----------|
| `Spectralizer-1.0.0-portable.exe` | 🖥️ Portable Windows (без установки) |
| `spectralizer-vst-v1.0.0-windows-vst3.zip` | 🔌 VST3 для Windows |
| `spectralizer-vst-v1.0.0-windows-clap.zip` | 🔌 CLAP для Windows |

### VST3 на Windows

1. Распакуйте zip  
2. Скопируйте `spectralizer-vst.vst3` в:
   - `%COMMONPROGRAMFILES%\VST3\`
3. Rescan плагинов в DAW  

### CLAP

Скопируйте `.clap` в папку CLAP вашего хоста (см. документацию DAW).

## 🛠️ Сборка из исходников

### Требования

- **Node.js** 20+  
- **Rust** stable (для VST)  
- Windows x64 для desktop `.exe`  

### Desktop

```bash
git clone https://github.com/grishinskeo-ship-it/Spectralizer.git
cd Spectralizer
npm install
npm run pack:portable
```

> ⚠️ Не держите проект в OneDrive — возможен `EPERM` при сборке.

### VST

```powershell
cd vst
cargo xtask bundle spectralizer-vst --release
```

Результат: `vst/target/bundled/spectralizer-vst.vst3`

**FL Studio (admin):**

```powershell
cd vst
powershell -ExecutionPolicy Bypass -File .\install-fl.ps1
```
